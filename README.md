# landingpage_repairindia

## Repair India - Premium Landing Page

A professional, modern landing page for Repair India - India's most trusted doorstep repair service for home appliances and electronics.

### Setup Instructions

1. Clone the repository:
```bash
git clone https://github.com/GitPawanGupta/landingpage_repairindia.git
```

2. Open `index.html` in your browser

3. For EmailJS functionality:
   - Create account at https://www.emailjs.com
   - Configure your email service
   - Update EmailJS credentials in `index.html`

### Testing Mobile Responsiveness

#### Desktop Browser DevTools:
1. Open Chrome/Edge DevTools (F12)
2. Click "Toggle Device Toolbar" (Ctrl+Shift+M)
3. Test different devices:
   - iPhone SE (375px)
   - iPhone 12/13 Pro (390px)
   - Samsung Galaxy S20 (360px)
   - iPad (768px)
   - Desktop (1920px)

#### Recommended Breakpoints:
- **Mobile:** 320px - 640px
- **Tablet:** 641px - 1024px
- **Desktop:** 1025px+
