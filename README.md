# landingpage_repairindia

## Repair India - Premium Landing Page

A professional, modern landing page for Repair India - India's most trusted doorstep repair service for home appliances and electronics.

### Features
- 🎨 Premium modern design with video background
- 📱 Fully responsive (mobile, tablet, desktop)
- 🚀 Fast loading with optimized assets
- 💼 Professional service cards
- 📞 Multiple contact options (Call, WhatsApp, Email)
- ✨ Smooth animations and hover effects
- 🔧 16+ appliance repair services

### Technologies Used
- HTML5
- Tailwind CSS (CDN)
- Font Awesome Icons
- EmailJS (for contact forms)
- Pure JavaScript

### Setup Instructions

1. Clone the repository:
```bash
git clone https://github.com/GitPawanGupta/landingpage_repairindia.git
```

2. Open `index.html` in your browser

3. For EmailJS functionality:
   - Create account at https://www.emailjs.com
   - Configure your email service
   - Update EmailJS credentials in `index.html`
